Branch Financial Reports

Filter every Odoo accounting report by branch — live, in one click. Four PDF reports included. Free & open source.

✓ Odoo 19 ✓ Free (LGPL-3) ✓ Accounting ✓ No Extra Dependencies

Key Features

🏢

Branch Units

Create unlimited branches with name, code, city, and manager. Organise your entire chart of accounts by branch.

📊

Live Filter in 5 Reports

A Branch dropdown appears inside General Ledger, Trial Balance, Balance Sheet, P&L and Partner Ledger — no reload needed.

🧾

Journal Entry Branch

Every journal entry (account.move) gets a Branch field so you can tag and trace transactions to the right location.

📄

4 PDF Reports

Print Profit & Loss, Balance Sheet, Trial Balance and General Ledger filtered by branch, date range and journals.

📅

Date & Journal Filtering

Every PDF wizard supports start date, end date, journal, and account filters alongside the branch selection.

🎯

Demo Data Included

3 sample branches (North, South, East) and 20 posted journal entries are installed automatically so you can explore immediately.

How to Use

1

Install the Module

Install Branch Financial Reports from Apps. Demo data is loaded automatically — 3 branches (North, South, East) and 20 posted journal entries are ready to explore immediately.

2

Create Your Branches

Navigate to Branch Reports → Configuration → Branches. Click New and fill in the branch name, short code, city and manager. Create as many branches as your organisation needs.

3

Tag Journal Entries with a Branch

Open any journal entry under Accounting → Journal Entries. The new Branch field is visible on the form — select the appropriate branch and save.

4

Filter Live Accounting Reports

Go to any of the 5 standard reports: General Ledger, Trial Balance, Balance Sheet, Profit & Loss, Partner Ledger. Click the Branch filter button and select one or more branches — the report updates instantly.

5

Print Branch PDF Reports

Go to Branch Reports → Reports, choose Profit & Loss, Balance Sheet, Trial Balance or General Ledger. In the wizard, select your branches, date range and optional journal/account filters, then click Print Report.
